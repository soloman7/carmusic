# 听电台方案 v4(实现规格实测收口版,2026-09-15)

> v3 架构全对,实现规格四发四中地塌:P1 无 limit 静默截断 57% 语料、P2 5s 超时下同步 100% 必败、
> P3 墓碑按"消失"判定会每周误杀活台、P4 Range 预热实测是无限下载且占监听槽位;F2 hidden 一字段
> 三语义会周期复活本地死台。四者与 changed 冻结同族:**规格写在 API 理想行为上,没写在实测行为上**。
> v4 制度升级:〇表从"架构决策的依据"扩展为"实现规格的依据"——方案里每一行 URL、超时、字节数,

## 三、架构决策

### D1 · 同步 = 分页全量重拉 + 三态 diff(v3 方案推倒重写)

```
周期任务(距上次 >7 天 && 避让播放):
  语料拉取(分页,每页独立事务,可断点续传):
    a. /stations/search?countrycode=CN&limit=5000,offset=0,500,1000…
       每页 5s connect + 60s total;Σ行数断言 ≥ countries.stationcount(CN)×0.8,
       否则本轮作废(防 P1 式截断静默入库)
    b. /stations/topvote?limit=1000&hidebroken=true(单次,73s/1.1MB)
  超时拆档:镜像健康检查/轻调用 = 5s connect + 10s total;
           语料分页 = 5s connect + 60s total/页(P2 实测 154s 全量,统一 5s 必败)
  三态 diff(v4 核心修正,health/deleted/localDeadUntil 三列互斥):
    upsert a∪b 全字段;
    lastcheckok=0 → health=down;lastcheckok=1 → health=ok(可见性由 health 管理,
    掉出 top1000 的台自然留在库里——b 集合成员资格流动,实测交集仅 9);
    本地有而 a∪b 无的 uuid → **不直接 hidden**,攒批进入复验队列;
    a 查询即便通过 0.8 断言仍可能截断 → 消失永远只怀疑、不处决
  墓碑(唯一的删除语义):收藏台后台复验时 /stations/byuuid?uuids= 批量查询,
    diff 输入/输出 uuid 集(实测:未知 uuid 静默丢弃),缺失 = 数据库确认删除 → deleted=1(永久)
  提交:每页独立事务,弱网部分成功可续传,不整轮重来
```

### D2 · PlaybackTarget 类型化(维持 v3,M1a 独立发版)

五处副作用(history/preload/重签链/persist 两入口/deadledger)按 sealed Music|Radio 分发。本轮全部发现(P1~P5、F2)均不触及此处——拆分的风险隔离价值已兑现。

### D3 · 模式仲裁(v4 补回退链终底)

维持 v3:冷启动 MUSIC/RADIO 一律只读不播(显式动作才出声);收藏 sortOrder+上下移;1 台 NEXT=重起流。
**0 收藏 NEXT 回退链补终底**:最后收听台 → 本省列表头部 → **seed topvote 第一名**(确定性兜底,不依赖省份/GPS/历史,链条永不落空),每层伴随 toast。

### D4 · NSC 决策 B(维持,无变化)

### D5 · 直播流规格(v4 修正)

- **错误恢复(维持 v3 本地优先)**:失败 → 本地 url 重起流一次(1s 退避)→ 仍败 → `localDeadUntil` 挂账(指数退避 24h/72h/7d)→ 驾驶态跳下一收藏台/非驾驶态提示。API 不在任何恢复路径上;后台复验(挂账台到期重验,byuuid 批量)是唯一的 API 刷新点。
- **三态可见性过滤**:列表 = `health==down || deleted || now<localDeadUntil` 任一命中即隐藏;**同步永不触碰 localDeadUntil**(消灭"每周复活本地死台"循环);localDeadUntil 台被用户手动点击 → 清零重试(用户意图优先)。
- **预热删除**:Range GET 预热从规格中移除(〇表 P4:直播流无视 Range,GET=无限下载+可能占满单 IP 监听槽位反噬真连接)。M2 车机实测起播基线后,若首帧确实超标,候选方案仅剩零流量形态:DNS 预解析 / TCP connect 后立即 cancel,**实现必须断言下载字节数 ≈ 0**。
- **码率(如实降级)**:"只显示 ≤N kbps 的电台"——CN 语料 bitrate=0 占 89%,该设置对 CN 覆盖 ~11%,主要价值在全球台;bitrate=0 = 放行 + 显示"码率未知",播放卡 MB/h 显示"—"。**真实省流轴手 = codec 字段(CN 质量待 M3 探针验证),不在本版承诺。**
- LiveConfiguration 仅 HLS/DASH;click 上报仅运行时;首启导入骨架态/失败重试(维持 v2/v3)。

## 七、验证计划(v4 补全)

- **断言清单终态**:字段存在性 / 时间新鲜度(<14 天)/ 单调性(真实执行,〇表示范)/ **完整性(行数下限 ≥ stationcount×0.8、Content-Length 或末字节校验)**。五类缺一不可——changed 拦死于第二类,P1 拦死于第四类。
- **PC 回归** `test_radio_api.py`:镜像轮转(≥1 存活)、CN 行数断言、抽 5 台拉流、收藏台全集 lastcheckok 复验(本地库驱动)。
- **单测**:seed 降级冲突;**topvote 掉榜 diff 场景(掉榜台不得 hidden)**;byuuid diff 缺失 → deleted;**同步不得触碰/复活 localDeadUntil**;五处副作用按类型分发;收藏循环 0/1/N 台与回退链四层;省份并集去重;码率过滤含 bitrate=0。
- **车机实网 = M1b 出口必要项**:镜像轮转同步成功一次(含行数断言通过)、飞行模式降级验收、3 台实播(含 1 HLS)、**20 分钟长播**(断流→重起流)、流量读数合理性。
